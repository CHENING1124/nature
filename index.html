# 大口呼吸 - 暖心手繪風格設計方向 ## Product Overview **The Pitch:** A single-page event portal for a forest slow-living experience. It invites users to disconnect from urban noise and reconnect with nature through mindful breathing and guided walks. **For:** Stressed urban professionals seeking weekend healing, digital detox, and a slower pace of life. **Device:** desktop **Design Direction:** A warm, tactile, hand-drawn aesthetic that mimics natural textures. Expect organic, slightly irregular lines, earthy forest tones, elegant serif and handwritten typography, and extreme whitespace to simulate visual "breathing room." **Inspired by:** Kinfolk editorial layouts, Japanese boutique ryokan landing pages (e.g., Hoshinoya). --- ## Screens Since this is a Single Page Application (SPA), "Screens" refer to the primary scrollable sections. - **Hero & Philosophy:** Immersive atmospheric entry introducing the core concept of mindful breathing. - **Event Details:** Practical itinerary, pricing, and hand-drawn route map. - **Nature Gallery:** Masonry layout showcasing the sensory experience of the forest. - **FAQ & Registration:** Frictionless, warm sign-up experience and common questions. --- ## Key Flows **Event Discovery to Registration:** Navigating the atmospheric journey to conversion. 1. User is on **Hero** -> sees full-bleed forest light photography and slow-fade typography 2. User scrolls to **Nature Gallery** -> clicks photo -> views expanded immersive image 3. User reaches **Registration** -> fills out oatmeal-colored form -> clicks **"報名慢生活"** 4. Form transforms into a hand-drawn success message with a bouncing leaf illustration ---
Design System ## Color Palette - **Primary:** `#4A6741` - Forest Green (Buttons, primary links, key icons) - **Background:** `#FDFBF7` - Off-white Paper (Global page background) - **Surface:** `#F4EFE6` - Oatmeal (Cards, form inputs, accordion backgrounds) - **Text:** `#2C332A` - Deep Pine (Headings, body copy) - **Muted:** `#8B9D85` - Sage Green (Secondary text, hand-drawn borders, placeholders) - **Accent:** `#D4A373` - Warm Clay (Hover states, highlights, success messages) ## Typography - **Headings:** `Shippori Mincho`, 700, 32-64px - **Body:** `Klee One`, 400, 16-18px - **Small text:** `Klee One`, 400, 14px - **Buttons:** `Shippori Mincho`, 500, 18px **Style notes:** Avoid rigid straight lines. Use `24px` border radii on cards. Apply a subtle grain filter `#noise` over the background. Use custom SVG borders that look drawn by hand (slight wobble, uneven stroke width). Space out typography with generous line height (`1.8` for body). ## Design Tokens ```css :root { --color-primary: #4A6741; --color-background: #FDFBF7; --color-surface: #F4EFE6; --color-text: #2C332A; --color-muted: #8B9D85; --color-accent: #D4A373; --font-heading: 'Shippori Mincho', serif; --font-body: 'Klee One', cursive; --radius-sm: 8px; --radius-lg: 24px; --radius-full: 9999px; --spacing-section: 160px; --spacing-element: 24px; } ```

Screen Specifications ### Hero & Philosophy **Purpose:** Establish mood, slow the user's scrolling pace, and introduce the event. **Layout:** 100vh full-bleed, vertically and horizontally centered content, bottom-anchored scroll prompt. **Key Elements:** - **Background Image:** Forest canopy with dappled sunlight. 30% opacity `#FDFBF7` overlay. - **Main Title:** `Shippori Mincho`, `64px`, `#2C332A`. Text: "大口呼吸". Surrounded by absolute-positioned SVG hand-drawn leaves. - **Scroll Indicator:** 1px vertical line `40px` tall, `#4A6741`. Text "往下探索" in `14px` `Klee One`. **States:** - **Loading:** Entire screen starts as solid `#FDFBF7`, image fades in over `1200ms`, title drifts up by `20px`. **Interactions:** - **Scroll down:** Background image uses a subtle parallax effect (slower than scroll speed). ### Event Details **Purpose:** Deliver logistical information without breaking the organic aesthetic. **Layout:** 2-column grid (`max-w-6xl`, centered). Left: Text data. Right: Illustration. **Key Elements:** - **Info Card:** `#F4EFE6` background, `24px` radius, subtle hand-drawn SVG border (`stroke="#8B9D85"`). - **Detail Items:** Icon + Label (`Shippori Mincho`, `#4A6741`) + Value (`Klee One`, `#2C332A`). - **Route Map:** Custom hand-drawn map illustration. No sharp container edges; blends into the `#FDFBF7` background. **Components:** - **Info Row:** `24px` gap, `1.5` line height, bottom border is a dashed hand-drawn SVG line. **Responsive:** - **Desktop:** 2 columns, map on right. ### Nature Gallery **Purpose:** Visual proof of the relaxing environment. **Layout:** 3-column CSS masonry grid, `max-w-6xl` centered, `24px` gaps. **Key Elements:** - **Photo Cards:** `16px` radius, varied aspect ratios (3:4, 1:1, 4:3). - **Caption:** Appears below photo on hover. `Klee One`, `#8B9D85`, `14px`. **Interactions:** - **Hover photo:** Image scales `1.03x` over `400ms` `ease-out`. Warm sepia filter drops to `0%`. ### FAQ & Registration **Purpose:** Address doubts and capture sign-ups warmly. **Layout:** Single narrow column (`max-w-2xl` centered) to maintain reading focus. **Key Elements:** - **Accordion Item:** `#F4EFE6` background, `16px` radius. Hand-drawn leaf icon rotates `180deg` on open. - **Form Inputs:** Height `56px`, `#F4EFE6` background, no visible borders, `16px` radius. `#2C332A` text. Placeholder `#8B9D85`. Focus ring `2px solid #4A6741`. - **Submit Button:** `100%` width, `64px` height, `#4A6741` background, `24px` radius. Text: "報名慢生活" (`Shippori Mincho`, `#FDFBF7`, `20px`). **States:** - **Form Empty:** Submit button opacity `0.5`, cursor `not-allowed`. - **Loading:** Button text replaces with bouncing leaf SVG. - **Success:** Entire form dissolves into a thank-you message with a hand-drawn stamp illustration. **Interactions:** - **Click Accordion:** Content slides down over `300ms` `cubic-bezier(0.4, 0, 0.2, 1)`.

Build Guide **Stack:** HTML + Tailwind CSS v3 + Alpine.js (for simple interactions like masonry and accordion) **Build Order:** 1. **Base Styles & Typography:** Import `Shippori Mincho` and `Klee One`. Setup Tailwind config with exact color hexes and border radii. 2. **Hero Section:** Build the full-bleed layout, overlay, and scroll animations to establish the "slow" tone immediately. 3. **Registration Form:** Implement the high-radius, borderless form inputs. Focus on the custom focus rings and hand-drawn button. 4. **Event Details & Gallery:** Implement the masonry layout and grid, focusing on exact spacing (`160px` between sections).
